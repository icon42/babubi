# Security Policy

## Supported versions

Only the latest Babubi release can get security fixes, on a best-effort basis: Babubi comes without support (see [SUPPORT.md](SUPPORT.md)), so a fix or even an answer is not guaranteed.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a vulnerability

Report vulnerabilities privately through GitHub: open the [Security tab of the repository](https://github.com/icon42/babubi/security) and choose "Report a vulnerability".

If the problem also affects Baby Buddy, which Babubi is forked from, report it to the [Baby Buddy project](https://github.com/babybuddy/babybuddy/security) as well.
