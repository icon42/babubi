# Support

Babubi is published in case it is useful to others, but it comes without support: there is no issue tracker, questions may go unanswered, and there is no commitment to fix bugs, to follow Baby Buddy releases or to keep publishing images. It is provided as is, without warranty of any kind, as stated in the [license](LICENSE).

For a supported baby tracker, use [Baby Buddy](https://github.com/babybuddy/babybuddy), which Babubi is forked from. Problems that also happen in Baby Buddy belong in its [issue tracker](https://github.com/babybuddy/babybuddy/issues).

Security problems can still be reported privately; see [SECURITY.md](SECURITY.md).
